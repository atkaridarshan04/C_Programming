An array is a collective name given to the group of similar quantities
Array is stored in stack .
An array is also known as a subscripted variable

Arrays of characters are called strings whereas an array of ints or floats is called
simply an array

Array is declared as
int xyz[i] = { 1,2,3,54,99 };   // similarly for float, int.
xyz is array or subscripted value where as i is subscript.

    [] - is dimension of array, it is optional to write subscript.

Array elements are always stored in contiguous memory locations.

IMPORTANT
num[i] = *(num + i) = *(i + num) = i[num]

------------------------------------------------------------------------------------

Multi-Dimentional Array are also calles as MATRIX

Two Dimentional
A 2-D array is a collection of several 1-D arrays

arr[5][3] --> The 1st subscript(row) value represnets the number of rows and 2nd subscript value(column) represent the no. of columns, whereas row subscript is optional but column subscript should be compulsory assigned. 

arr[i][j] = *(arr[i]+j) = *(*(arr+i)+j)



Three Dimentional Arrays are rarely uesd.
A 3-D array is a collection of several 2-D arrays.

All elements of a 2-D or a 3-D array are internally accessed using pointers.
